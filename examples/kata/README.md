# kata

Shared method library for math, mathematical physics and quant work, synced across Claude, ChatGPT, Gemini, Grok, NotebookLM, Copilot.

Two jobs:
- Internalize methods: `KATA.md` (Tier 1 structural, Tier 2 technique). Run `python kata_to_anki.py` and import the CSV into Anki for spaced review.
- Look up what we tried: `LOG.md`, dated attempts including failures. Search with `grep -i floer LOG.md KATA.md`.

Files:
- `KATA.md` canonical library. Edit here only.
- `LOG.md` lab log, newest first.
- `RULES_for_other_models.txt` custom instructions for other models.
- `kata_to_anki.py` Tier 2 -> Anki CSV.
