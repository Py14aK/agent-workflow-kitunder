# ADHD skill prompts

Date: 2026-10-07.

One skill per chat. Paste the block. Attach the file. Stop when the skill says stop.

## Data analysis

```
SKILL: adhd-data-analysis
QUESTION: (one figure or comparison)
SOURCE: attached or NOT SUPPLIED
Print NOW DONE NEXT BLOCKED. One table. Reconcile once. Stop.
```

## Runbook

```
SKILL: adhd-runbook
JOB: (one procedure)
TRIGGER: (what starts it)
Write 5 to 9 checkbox steps. Each step has a done-check. End with rollback. Stop.
```

## Project

```
SKILL: adhd-project
OUTCOME: (one sentence)
NOW: (one item or EMPTY)
Park every other outcome under LATER. Time box the NOW item. Stop.
```

## Presentation

```
SKILL: adhd-presentation
AUDIENCE: (who decides)
ASK: (one decision)
SOURCE: attached or NOT SUPPLIED
Five slides. Unverified points stay in speaker notes. Stop.
```

## Coach

```
SKILL: adhd-coach
TASK: (what is in front of me)
Give one next action under 10 minutes and one done-check. Do not list options. Stop.
```
