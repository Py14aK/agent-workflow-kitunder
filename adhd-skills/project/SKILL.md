# ADHD project

One outcome. Three columns. No second project in this turn.

## State line, print first

NOW:
DONE:
NEXT:
BLOCKED:

## Steps

1. Write the outcome in one sentence. If two outcomes appear, keep the one named first and park the other under LATER.
2. Split work into NOW (one item), NEXT (max 3), LATER (titles only), BLOCKED (needs a person or a fact).
3. Each NOW item has an owner, a done-check, and a time box of 25 or 50 minutes.
4. Do not assign a due date that was not in the source. Missing date is UNKNOWN.
5. Print a 5-line status a person can read aloud. No preamble.
6. Print the state line. NEXT is the single NOW item, or STOP.

## Do not

- Do not build a full Gantt chart.
- Do not restack priorities unless the user asks.
- Do not close a blocker by guessing the answer.
