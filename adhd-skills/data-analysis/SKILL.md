# ADHD data analysis

One question. One source. One number. Then stop.

## State line, print first

NOW:
DONE:
NEXT:
BLOCKED:

## Steps

1. Name the decision the number supports. If unnamed, ask one question and stop.
2. Name the source file, sheet, and date. If missing, write NOT SUPPLIED and stop.
3. Keep source column names exactly. Do not rename.
4. Compute only the asked figure. Reconcile it once against a second total or row count.
5. Print one table, max 8 rows. Extra rows go under MORE, count only.
6. Mark each line FACT, CHECKED, or UNKNOWN.
7. Print the state line again. NEXT is one action, or STOP.

## Do not

- Do not open a second dataset.
- Do not add a chart unless asked.
- Do not invent a missing value. Write UNKNOWN.
- Do not claim a run unless the tool result is in this turn.
